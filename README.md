# GSE - Gestor de Obras

Sistema de gestión de obras con backend Node.js y frontend React.

## Estructura

```
gse/
├── backend/     (Node.js + Express)
└── frontend/    (React + Vite)
```

## Instalación

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Tecnologías

- **Backend:** Node.js, Express, Prisma, PostgreSQL
- **Frontend:** React, Vite, Tailwind CSS
